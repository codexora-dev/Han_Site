설치 및 다운로드

Han을 설치하고 바로 시작하세요.

현재 저장소에는 공식 릴리스 파일이 공개되어 있지 않으므로, 가장 현실적인 설치 방법은 GitHub 저장소에서 소스를 내려받고 IDE를 실행하는 것입니다.

Windows

프로젝트를 다운로드한 뒤 아래 명령으로 Han IDE를 실행합니다.

cd C:\Users\사용자명\Desktop\Han
python IDE\app.py

기존 저장소 구조를 그대로 사용하고, IDE 화면에서 .han 파일을 작성해 실행할 수 있습니다.

GitHub 저장소

macOS

macOS 환경에서는 Python 3를 사용해 IDE를 실행합니다.

cd /경로/To/Han
python3 IDE/app.py

설치 파일이 준비되기 전까지는 소스 기반 설치가 현재 가장 정확한 방법입니다.

GitHub 저장소

공식 릴리스 상태

현재 Han은 초기 개발 단계 프로젝트이며, 공식 설치 패키지 또는 독립 실행 파일이 별도로 배포될 때까지 GitHub 저장소의 소스 실행이 가장 정확한 이용 방법입니다.

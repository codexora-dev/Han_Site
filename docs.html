문서

Han의 현재 문법과 사용 흐름을 정리한 문서입니다.

아래 내용은 저장소에 실제로 존재하는 예제와 문서를 기준으로 정리했습니다.

시작하기

Han 프로젝트를 다운로드하고 IDE로 첫 코드를 작성하는 기본 절차를 확인합니다.

기본 문법

주석, 줄바꿈, 식별자, 변수 선언, 출력과 같은 기본 문법 개념을 살펴봅니다.

출력

출력 문은 값이나 문자열을 화면에 표시합니다.

출력 "안녕하세요, Han!"

변수

변수를 선언하고 값을 저장하며 계산에 활용합니다.

변수 넓이 = 8 * 5
출력 넓이

입력

사용자 입력을 받아 변수를 저장할 수 있습니다.

입력 이름 "이름을 입력하세요: "
출력 "안녕하세요, " + 이름

조건문

만약과 아니면으로 흐름을 나누고, 비교 연산자를 사용할 수 있습니다.

만약 점수 >= 60
    출력 "합격입니다."
아니면
    출력 "다음 기회에 도전하세요."
끝

반복문

반복 문은 같은 동작을 정해진 횟수만큼 실행합니다.

변수 횟수 = 3
반복 횟수
    출력 "Han을 연습합니다."
끝

함수

함수는 재사용 가능한 코드 단위로 구성됩니다.

함수 인사(이름)
    출력 "안녕하세요, " + 이름
끝

자료형

문서상으로는 정수, 실수, 문자열, 논리값, 목록 등의 기본 자료형 개념이 제안되어 있습니다.

연산자

산술 연산자, 비교 연산자, 논리 연산자가 예제로 사용됩니다.

만약 나이 >= 19 그리고 학생
    출력 "학생 할인 대상입니다."
끝

오류 해결

잘못된 문법, 정의되지 않은 이름, 자료형 오류, 0으로 나누기 등을 한국어로 설명하는 방향을 지향합니다.

Han IDE 사용법

파일 탐색기, 편집기, 실행, 콘솔, 오류 복사 기능을 중심으로 사용 방법을 안내합니다.
